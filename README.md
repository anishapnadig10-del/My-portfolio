# Anisha's Personal Portfolio Website

A bold, modern, and colorful personal portfolio built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Features

- **Navbar**: Sticky frosted glass navigation with brand name on the left, smooth-scrolling links on the right, and a responsive mobile hamburger menu.
- **Hero**: Large bold typography, one-line intro, college affiliation badge (BIT CSE), and two CTA buttons: *"View my work"* (smooth scrolls to Projects) and *"Contact me"* (smooth scrolls to Contact).
- **About**: 2-3 line background story, BIT Bangalore education card, and colorful skill chips highlighting **C++**, **C**, **Python**, and web technologies with interactive hover effects.
- **Projects**: Clean, responsive project grid utilizing a reusable `<ProjectCard />` component, tech-stack tags, and direct GitHub links.
- **Contact**: Interactive UI form (Name, Email, Message) with client-side feedback toast, 1-click email copy button (`anishapnadig10@gmail.com`), and direct links to GitHub and LinkedIn (`anishapnadig10-del`).
- **Footer**: Sleek copyright section (`© 2026 Anisha`) with social links and a smooth back-to-top button.
- **Design System**: Deep black aesthetic accented with vibrant gradients (neon pink, purple, cyan, emerald), glassmorphism cards, and subtle hover animations.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Autoprefixer
- **Design Style**: Bold and Colorful on a deep black palette

---

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view your live portfolio!

### 3. Build for Production
```bash
npm run build
npm start
```
